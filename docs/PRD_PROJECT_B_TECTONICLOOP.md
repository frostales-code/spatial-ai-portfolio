# Project B 产品策划案：TectonicLoop — 视觉表现与物理建构/造价双向反馈引擎

> **产品定位**：面向商业空间微更新、建筑外立面及精品室内设计的「建构深化排雷与动态价值工程（Interactive VE）工作台」  
> **核心价值主张**：终结“效果图诈骗（Render-to-Reality Gap）”。不仅将惊艳的概念渲染图自动拆解为**可落地的构造层次、真实建材模数、标准节点与多梯度造价**，更打通**工程与预算约束反向精准重绘设计图**的双向闭环。

---

## 一、 行业真痛点与场景收敛策略（Problem & Scope Strategy）

### 1.1 为什么“只管出好看的图”在工程端是伪命题？
1. **AI 渲染图的物理与规范幻觉**：通用生图模型缺乏重力、材料极限尺幅与构造防水常识——常见生成 6 米宽无缝单块超白玻、无滴水线与防潮勒脚的室外浅色涂料墙、零结构厚度的悬挑雨棚。概念过稿越顺利，深化与施工阶段推倒重来的代价越惨烈。
2. **设计与造价/采购的单向割裂**：传统流程中，方案图画完后交由预算员算账，两周后告知“超支 $60\%$”；设计师被迫拍脑袋砍材料（如把天然石材降级为铝板或涂料），却无法在汇报现场快速向甲方展示**“降本换工艺后，真实的板材拼缝、光泽变化与收口细节长什么样”**。

### 1.2 极具克制性的 MVP 场景边界（工程可行性护栏）
* **垂直切入高标准化场景**：首期聚焦 **商业街区门头与立面改造、90~300㎡ 精品餐饮/零售商业空间、城市景观构筑物**。该类项目 $80\%$ 的造价弹性与视觉品质集中在**表皮装饰系统、门窗幕墙分格、龙骨挂装工法与灯光软装**，规避主体复杂结构抗震验算。
* **引入“最小尺度锚点（Minimal Scale Anchor）”**：拒绝吹嘘“单张 2D 图盲猜工程量”。要求用户导入渲染图时提供一个基准尺度锚点（如框选门洞输入标准高 $2.2\text{ m}$ / 层高 $3.6\text{ m}$，或直接读取上游 SketchUp/Rhino 白模导出的 Depth 深度图与构件面积表），确保板材分缝模数与概算区间具备真实工程参考价值。

### 2.1 正向链路（Forward Pass）：渲染图自动排雷与多梯度落地补全
1. **构件级语义解构与尺度反推**：结合 SAM 2 分割、Depth Anything 深度估计与基准尺度锚点，自动切分出外墙饰面、玻璃幕墙、雨棚檐口、地面铺装等独立图元，估算各图元净面积与最大跨度。
2. **AI 物理建构幻觉排雷引擎（Constructability Linter）**：对比内置《常见饰面极限制造尺幅与构造禁忌规则库》，自动在原图叠加红色高亮预警锚点（如超宽单块玻璃、室外无泛水压顶、异种材料无伸缩缝硬碰、商场禁湿作业冲突）。
3. **高/中/低三档同效异构方案补全（Multi-Tier VE Mapping）**：针对同一视觉肌理诉求，利用垂直建材与造价 RAG 自动匹配三套真实可采购工艺包（如：**高定干挂天然石材** vs **中端预制 UHPC/纤维水泥挂板** vs **快装柔性无机石材切片/艺术涂料分格**），同步输出构造层次、标准节点简图及动态总价区间。

### 2.2 反向链路（Reverse Pass）：工程与预算约束反向精准改图
当设计师或甲方在右侧工程面板调整约束（如：**“总预算锁死 $\le ¥8\text{ 万}$”**、**“工期 $\le 10\text{ 天}$（全干法装配）”** 或 **“将无缝弧墙改为 $1200\text{ mm}$ 标准平板明缝拼装”**），系统触发三层确定性视觉回写：
1. **全局约束求解（Constraint Solver）**：在满足总价与工期红线的前提下，自动为超标构件降级或替换最优性价比工艺包，重算综合造价表。
2. **透视模数分缝线框程序化合成（Perspective-Correct Seam Wireframe）**：根据新选定板材的物理出厂尺寸（如 $600\times 1200\text{ mm}$，留 $10\text{ mm}$ 工艺黑缝），顺着该区域的三维平面法线与透视灭点，程序化生成严格符合近大远小透视关系的**构件分缝与收口压条线框控制图**。
3. **光照锁定的局部受控重绘（Relighting-Locked Inpainting）**：锁定原图非修改区域、相机机位与全局环境光（IBL），将【局部蒙版 + 透视分缝 ControlNet 线框 + 真实产品 PBR 材质贴图特征】送入重绘管线，使原图在保留设计神韵的前提下，真实长出挂板拼缝、金属压顶泛水条、窄边框分格钢窗及准确的表面反射率变化。

## 三、 核心技术难点与攻克方案（Core Technical Challenges）

### 难点 1：2D 透视图上的真实物理模数分缝投影（Perspective-Aware Modulus Projection）
* **问题本质**：如果直接用文字 Prompt 让生图模型“在墙上加上 $1.2\text{ m}$ 宽的干挂板拼缝”，模型画出的分缝间距完全随机、竖线歪斜，甚至破坏原有门窗洞口结构，毫无工程严肃性。
* **工程解法**：**几何确定性前置计算，绝不让扩散模型猜尺度**。利用单目深度点云反推或白模导出的平面方程提取目标墙面的单应性矩阵（Homography Matrix $H$）；在正交二维展开平面上按真实物理毫米尺寸（如 $1200\times 2400\text{ mm}$、错缝或对缝排版、避让门窗洞口）由确定性算法绘制精确 CAD 级网格，再经 $H^{-1}$ 逆投影回原图相机透视空间生成 Canny/Depth 引导图，最后仅让扩散模型负责填充缝隙阴影（Ambient Occlusion）与边缘倒角质感。

### 难点 2：局部换材重绘时的环境光照一致性与色彩溢出
* **问题本质**：将原本漫反射的暖灰石材立面替换为氟碳金属板或穿孔铝板时，常规 Inpainting 极易把材质画得像廉价 PS 贴图，丢失原图树影投射、黄昏色温及周边地面的环境光反弹。
* **工程解法**：**本征图像分解（Intrinsic Image Decomposition）管线**。在重绘前先将原图分解为反照率层（Albedo）与光照阴影层（Shading / Irradiance Map）；材质替换与分缝注入主要作用于 Albedo 与表面粗糙度（Roughness/Normal）通道，并在合成阶段重新耦合原图的 Shading 树影遮罩层，确保换完低成本材料后，光影逻辑依然 $100\%$ 融于原场景。

### 难点 3：非标建材价格波动与垂直构造知识库幻觉抑制
* **问题本质**：通用大模型对地方人工辅材单价、龙骨损耗系数及冷门节点做法极易编造虚假数据，一旦报错单价会直接摧毁专业用户信任。
* **工程解法**：**规则引擎算账 + 图谱化建材 SKU 库（Zero-LLM Arithmetic）**。严禁大模型直接口算造价！知识库底层按【构件部位 - 基层条件 - 构造做法包 - 地区物价指数】建立关系型定额宽表；LLM/VLM 仅负责“视觉肌理分类与构造包匹配路由”，所有面积折算、损耗系数（如板材裁切损耗 $1.08 \sim 1.15$）、龙骨辅材摊销及总价汇总全部由确定性代码计算，并强制展示单价区间（如 `¥520 ~ ¥640 /㎡`）与数据基准日期。

## 四、 量化评测体系（Eval-Driven Development Scorecard）

| 评测维度 | 核心指标定义 | Baseline（传统人工 / 通用多模态） | Target（TectonicLoop V1.0） | 评测方法 |
| :--- | :--- | :--- | :--- | :--- |
| **建构隐患检出率** | 对超限尺幅、缺失泛水/勒脚、不合理湿作业等预设工程缺陷的召回率 | $28\%$（通用 GPT-4o/VLM 直接看图） | $\ge 85\%$ | 50 张含典型落地陷阱的商业空间测试集 |
| **分缝透视几何误差** | 反向重绘后板材拼缝与透视灭点及目标物理模数比例的像素偏离度 | 不可控（纯 Prompt 间距方差 $>40\%$） | 透视角度误差 $< 1.5^\circ$ | 单应性网格重投影自动化几何校验 |
| **概算区间命中率** | 系统输出综合造价区间覆盖真实竣工结算单方造价的比例 | 人工深化询价耗时 $2 \sim 3$ 天 | $\ge 80\%$ 落在 $\pm 15\%$ 区间内（耗时 $<15\text{ s}$） | 20 个已竣工商业门头/咖啡馆历史结算单回测 |
| **非修改区像素保持率** | 反向修改单一构件后，未选中区域（天空、配景、其他立面）的结构无损度 | 整图重绘漂移严重 | Mask 外区域 $\text{PSNR} \ge 38\text{ dB}$ | 图像差分自动化回归测试 |

## 五、 分阶段研发路线图（Product Roadmap）

* **Phase 1：商业门头垂直库与正向排雷原型（Week 1 - Week 3）**
  * 搭建涵盖 40 种高频外立面与室内饰面工艺的结构化定额与标准节点库（石材、UHPC、金属板、涂料、木饰面、玻璃幕墙系统）；跑通“上传效果图 + 尺度锚点 → 分割排雷 + 三档造价表输出”正向闭环。
* **Phase 2：透视模数网格合成与反向改图管线（Week 4 - Week 6）**
  * 攻克单应性透视分缝生成器与光照锁定局部重绘（ComfyUI API / 自定义 ControlNet 管线），实现“改预算/改板幅 → 实时同步更新渲染图拼缝与质感”。
* **Phase 3：上游白模直连与 BOM 采购清单导出（Week 7 - Week 8）**
  * 支持直接导入 Rhino / SketchUp 视口截图及材质通道图（免除手动标定尺度），一键导出带图文对照、节点索引及甲乙双方汇报对比视图的深化任务书 PDF。
