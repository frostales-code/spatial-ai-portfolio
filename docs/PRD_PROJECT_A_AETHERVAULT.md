# Project A 产品策划案：AetherVault — 基于正交美学光谱与解耦编译的设计师外脑

> **产品定位**：面向空间、工业及视觉设计师的「个人隐性审美资产化与确定性风格编译工作台」  
> **核心价值主张**：跨越“模糊氛围直觉”到“高精度受控视觉生成”之间的语义鸿沟——用 **8 维连续美学光谱 + 正交特征解耦检索** 替代低效的关键词抽卡与黑盒 CLIP 搜索，低成本实现免训练 LoRA 的个人审美对齐。

---

## 一、 商业背景与核心痛点诊断（Why Now & Problem Space）

### 1.1 现有工具链的三大断层
1. **存图工具“只存不醒”（Eagle / Pinterest / Cosmos）**：设计师本地囤积数千张高审美参考图，但传统标签仅停留在物体表象（如 `#混凝土`、`#室内`、`#椅子`）。当脑海里浮现一个模糊复合意图（如*“带点荒野孤寂感、但构件交接像精密光学仪器一样克制”*）时，传统关键词搜索完全失灵。
2. **通用多模态检索的“CLIP 主体耦合陷阱”**：原生 CLIP 向量将**画面内容（What）**与**美学形式（How）**强绑定。当建筑师想寻找某种特定的“阴天漫反射冷调光感”时，即使一张高定服装大片或工业摄影具备完全一致的光影张力，也会因主体不同而在检索中被过滤。
3. **下游生图的“多图污染与提示词玄学”**：设计师往往喜欢图 A 的镜头透视、图 B 的材质肌理、图 C 的色温情绪。直接将三张图喂给多模态生图模型（IP-Adapter / Reference）会导致特征互相打架、画面结构崩塌；而手写光学与材质级 Prompt 门槛极高且结果不可复现。

### 1.2 非 AI 与 AI 的产品边界界定（PM 架构克制性）
* **用 AI 做的事**：入库图像的自动化美学解耦打标（VLM）、自然语言模糊意图向多维光谱向量的映射、正交视觉特征向结构化光学/材质 Prompt 的无冲突编译。
* **坚决不用大模型硬算的事**：前端审美探索与微调重排。一旦资产转化为 **8 维连续光谱向量**，用户拖动滑块微调“冷暖/粗粝度/留白感”时，直接通过前端/轻量向量库执行毫秒级加权余弦距离计算（延迟低于 $50\text{ ms}$），拒绝在高频交互中引入缓慢且昂贵的多轮 LLM 对话。

## 二、 核心产品架构与数据本体设计（System Architecture & Ontology）

### 2.1 八大正交连续风格光谱（8-Axis Bipolar Style Spectrums）
抛弃主观且易过时的流派标签（如“侘寂风”、“赛博风”），基于客观视觉形式建立取值范围为 $[-1.0, +1.0]$ 的连续双极标尺，每个维度配套显著度权重 $s_i \in [0.0, 1.0]$：

| 维度 ID | 负向极值 ($-1.0$) | 正向极值 ($+1.0$) | 跨媒介特征定义 |
| :--- | :--- | :--- | :--- |
| `tectonic_honesty` | **消隐包覆 (Monolithic)**：无缝一体、隐藏构造交接 | **结构外露 (Tectonic)**：杆件穿插、紧固件与节点诚实暴露 | 构造表现度 |
| `surface_entropy` | **精密出厂 (Pristine)**：阳极氧化、镜面抛光、零瑕疵工业感 | **风化包浆 (Weathered)**：粗骨料气孔、氧化锈蚀、时间侵蚀感 | 肌理时间熵 |
| `spatial_density` | **克制负空间 (Austere)**：大面积呼吸留白、单一视觉重心 | **高密层叠 (Layered)**：前景/中景/远景高密度信息堆叠 | 信息熵与留白 |
| `geometric_order` | **有机流体 (Biomorphic)**：自然生长曲面、非对称自由形态 | **严苛模数 (Orthogonal)**：正交轴网控制、硬朗几何切分 | 几何形态秩序 |
| `lighting_drama` | **全局漫射 (Diffused)**：阴天柔光箱效应、消解硬投影 | **戏剧切割 (Chiaroscuro)**：高反差硬光、丁达尔体积光束 | 光影反差度 |
| `chromatic_tension` | **消色差灰调 (Muted)**：莫兰迪低饱和、单色系明度微差 | **高纯度对冲 (High-Chroma)**：互补色强碰撞、高饱和张力 | 色彩能量张力 |
| `thermal_mood` | **冷峻智性 (Clinical Cool)**：实验室疏离感、理性克制 | **温润松弛 (Intimate Warm)**：触觉包裹感、温暖居心地氛围 | 情绪色温亲疏 |
| `reality_abstraction` | **光学纪实 (Photorealistic)**：真实镜头畸变与物理级材质 | **图形构成 (Graphic Stylized)**：扁平色块抽离、插画构成感 | 写实与抽象度 |

### 2.2 四层解耦资产 JSON Schema
每张入库图片经多模态流水线解析为独立存储的四个正交命名空间：
1. `subject_isolation`：领域分类（建筑/工业/摄影/服装/插画）、核心主体描述（用于正向锁定或**跨界反向排除**）。
2. `style_spectrums`：8 维连续分值 `score` 与显著度 `salience` 向量。
3. `granular_descriptors`：物理级细粒度槽位——`optics_camera`（等效焦段、机位仰俯、景深）、`lighting_rig`（主光方向、环境雾气）、`material_stack`（主次材质及表面处理工艺）、`color_palette`（主辅色 HEX 占比）。
4. `compiler_primitives`：预提炼的正向风格原语（Tokens）与防崩坏负向护栏（Negative Guardrails）。

### 2.3 核心业务状态流转（5-Step State Machine）
1. **模糊意图投影**：用户输入感性描述 → 轻量模型解析为目标光谱向量 $\mathbf{v}_{target}$、显著度掩码 $\mathbf{m}$ 及硬性负向过滤词。
2. **双轨混合召回（Dual-Track RAG）**：
   * **内环（个人审美先验）**：在个人私有库按加权距离检索，对齐设计师个人审美基准线（Taste Centroid）。
   * **外环（跨界灵感破圈）**：锁定 `style_spectrums` 与 `lighting_rig`，强制设置过滤条件 `domain != target_domain`，从服装、电影摄影、精密工业产品中召回同构美学参考。
3. **视觉二分校准（Visual A/B Calibration）**：拒绝文字盘问，直接呈现两组存在微妙光谱分叉的视觉卡片 + 动态雷达滑块，2 轮点击内收敛意图。
4. **正交特征混音台（Orthogonal Feature Mixer）**：支持用户指定“继承图 A 的光学透视 + 图 B 的材质栈 + 图 C 的光影色调”，在数据结构层物理隔离不同维度。
5. **确定性风格编译与资产回流**：按无冲突语法树组装结构化生图 Prompt 与控制参数，高分生成图一键回流个人库并继承光谱坐标。

## 三、 核心技术难点与攻克方案（Core Technical Challenges）

### 难点 1：VLM 连续数值打标的尺度漂移（Score Drift & Calibration）
* **问题本质**：直接让多模态大模型对单张图片输出 $[-1.0, +1.0]$ 浮点数，不同批次、不同主体间会出现严重的打分漂移（例如同一种清水混凝土今天打 `0.5`，明天打 `0.85`），导致向量空间失真。
* **工程解法**：
  1. **五点基准锚点注入（5-Point Few-Shot Anchoring）**：为每个光谱轴建立包含 $-1.0, -0.5, 0.0, +0.5, +1.0$ 标准参考图及明确物理判据的黄金标尺库，采用成对比较（Pairwise Ranking / Reference-guided Scoring）替代绝对盲打。
  2. **显著度门控距离公式（Salience-Gated Metric）**：检索距离计算采用加权马氏/余弦变体：
     $$D(\mathbf{q}, \mathbf{x}) = \frac{\sum_{i=1}^{8} w_i \cdot s_{x,i} \cdot (q_i - x_i)^2}{\sum_{i=1}^{8} w_i \cdot s_{x,i} + \epsilon}$$
     其中 $w_i$ 为查询意图在该维度的关注权重，$s_{x,i}$ 为候选图在该维度的显著度，彻底消除局部材质特写图在宏观空间维度上的噪声干扰。
  3. **隐式交互校准闭环**：用户在画布中手动拖拽调整某张图的光谱滑块或归入自定义流派聚类时，触发轻量级贝叶斯坐标更新，越用越准。

### 难点 2：多参考图正交编译时的“语义污染与词条互斥”
* **问题本质**：当用户混搭“图 A（极简无缝几何体量）”与“图 B（高熵风化岩石肌理）”时，简单拼接两张图的描述词会产生逻辑悖论（`pristine seamless surface` vs `heavily eroded rough surface`），导致生图模型注意力崩塌。
* **工程解法**：构建 **AST 级风格语法编译器（Conflict-Free Prompt AST）**。编译器严格按【主体骨架层 → 镜头光学层 → 构件材质绑定层 → 全局光影大气层 → 负向排斥层】分配槽位作用域；当检测到跨图光谱极值冲突时，强制将材质词限定在局部构件作用域（Region/Component Scoping），并自动剔除被未勾选维度连带引入的冲突形容词。

### 难点 3：入库解析成本与冷启动体验延迟
* **问题本质**：设计师首次导入本地 Eagle 文件夹可能包含 500~2000 张高清参考图，若全量同步调用旗舰级多模态大模型，API 成本高且等待时间长达数十分钟。
* **工程解法**：**端云分级异步管线**。本地/轻量端先用极低成本提取主色调 HEX、图像清晰度与基础 Embedding 实现 3 秒内立即可搜；后台异步队列采用 Batch API 结合高性价比视觉小模型（如微调 Qwen-VL / Gemini Flash 级模型）分批补全 8 维光谱与细粒度 JSON，单张入库综合成本压控在 ¥0.008 以内。

## 四、 量化评测体系（Eval-Driven Development Scorecard）

| 评测维度 | 核心指标定义 | Baseline（原生 CLIP / 手写 Prompt） | Target（AetherVault V1.0） | 评测方法 |
| :--- | :--- | :--- | :--- | :--- |
| **跨媒介风格召回率** | 给定模糊氛围词，Top-5 召回结果中跨领域但审美高度同构的有效率 | $31\%$（严重受限于同主体） | $\ge 82\%$ | 100 组黄金模糊查询盲测集 |
| **光谱打标一致性** | 同一图片多次解析及与资深设计师人工标定排序的斯皮尔曼相关系数 $\rho$ | $0.54$（无锚点直接打分） | $\ge 0.86$ | 200 张多门类基准锚点回归测试 |
| **意图收敛交互轮次** | 从输入模糊想法到锁定满意参考图组的平均操作步数 | $6.8$ 轮纯文本对话修改 | $\le 2.2$ 次视觉校准点击 | 可用性走廊测试埋点 |
| **正交混音忠实度** | 编译生图结果在指定继承维度（如仅继承图 A 光影 + 图 B 材质）的解耦达成率 | $45\%$（多图直喂严重串色） | $\ge 85\%$ | VLM-as-a-Judge 分维度盲评量表 |

## 五、 分阶段研发路线图（Product Roadmap）

* **Phase 1：MVP 核心闭环（Week 1 - Week 3）**
  * 固化 8 维美学光谱定义与黄金锚点提示词，完成本地 300 张高审美跨界样本入库解析脚本；搭建光谱雷达检索与双轨召回 Web 原型。
* **Phase 2：正交混音与生图管线打通（Week 4 - Week 6）**
  * 实现多图槽位特征拾取器（Feature Picker）与无冲突 Prompt AST 编译器，打通下游生图 API / ComfyUI 节点，实现生成资产一键回流建档。
* **Phase 3：个人品味画像与流派预设（Week 7 - Week 8）**
  * 上线“个人审美重心（Taste Centroid）”可视化分析与“框选 5 张图一键生成自定义风格滤镜（Named Cluster）”功能，完善离线自动化 Eval 看板。
