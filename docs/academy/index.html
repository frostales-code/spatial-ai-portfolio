一、第一性原理：如何判断「该用 AI 还是代码」与「该选轻还是选重」

所有 7 个项目（从 Spatial AI 到 RAG 再到 Multi-Agent）底层都共享这三条不可动摇的工程心法。

RULE 01 · AI VS DETERMINISTIC

语义交给模型，数学/物理/状态交给代码

大模型只做三件事：非结构化语义理解（离线打标、意图解析）、跨模态生成、锚点主观复核。凡是排序、颜色距离、透视矩阵、整箱造价、进程生命周期和审批幂等，100% 用确定性代码兜底。

RULE 02 · FAIL-CLOSED HONESTY

未知态宁可暂停报错，绝不静默归零或盲目重试

Aurora 缺价必报 UNKNOWN_PRICE_MISSING、Super Agent 进程失联锁死槽位宁暂停不重发、Taste Engine 反差合格不足宁欠填不凑数——让错误停在显性边界，比伪造“看起来成功”重要十倍。

RULE 03 · EARN YOUR COMPLEXITY

每一层重型框架都必须用实测瓶颈“换取入场券”

1,500 条向量用 NumPy .npz 耗时 <2ms，根本不需要 Qdrant 集群；单机持久化用 SQLite WAL 扛得住十万级记录，就别为“显得专业”先上 PostgreSQL + Redis + Docker Compose。
